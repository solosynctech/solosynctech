# SoloSyncTech

Single-file company homepage for GitHub Pages.

The site is intentionally dependency-free: all HTML, CSS and JavaScript live in `index.html`.

## GitHub Pages

Publish the repository root from the `main` branch using GitHub Pages. GitHub Pages serves static files directly from a repository.

For a custom domain such as `solosync.live`, configure the domain under repository Settings → Pages and add the required DNS records.

## Local preview

Open `index.html` directly in a browser, or serve the directory with any static HTTP server.
